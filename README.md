# Camilla Du Preez — Social Media Portfolio

Personal portfolio site for social media and digital communications work. This public repository contains the source code and the portfolio visuals used by the site.

## Website

The built site is published at https://camillaspica.github.io/. Every push to `main` builds the site from `src/` and deploys the result.

## Updating the site

Edit the source in `src/` and push to `main`. The Pages workflow installs dependencies, runs `npm run build` and publishes the fresh `dist/` folder, so you no longer need to build locally first.

After purchasing a custom domain, add it in this repository's Pages settings.
